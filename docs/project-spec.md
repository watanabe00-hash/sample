## プロジェクト概要
猫が自由に暴れまわる、Windowsアプリケーション。
ユーザー操作にて、猫を自由自在にコントロール。

## 技術スタック
- Python
- HTML
- SCSS
- javascript
- json

## ディレクトリ構成
- ソースコードは`source`配下にFunction単位で出力する。

## データモデル
- 猫の画像として、黒猫、白猫等のBLOB
- 鳴き声のBLOB
- SaveデータをJsonで保持

## 機能一覧
- アプリケーションフレームはPythonで実施
- インブラウザにて、猫ちゃんをDOMで自由に動かす
- 猫ちゃんをクリックすると鳴く
- 猫ちゃんをダブルクリックすると２匹に増える
- Saveすると次ブラウザを開いた際に読み込み
- 最初１匹で上記動作をすることで増える。
