# 猫ちゃんズ テスト仕様書

## 動作確認手順

### 1. アプリケーションの起動
- **方法 A (Pythonサーバー起動)**:
  ```bash
  python source/main.py
  ```
  実行後、ブラウザが自動的に開き `http://127.0.0.1:8000/index.html` に接続されます。
- **方法 B (ブラウザ直接オープン)**:
  `source/static/index.html` を任意のブラウザ（Chrome / Edge 等）で直接開きます。

### 2. 機能検証チェックリスト
- [x] **初期表示**: ステージ中央に最初の1匹（白猫「ユキ」）が表示され、画面内を自律してトコトコ歩き回る。
- [x] **クリック (鳴く)**: 猫をクリックするとWeb Audio APIで可愛い鳴き声が鳴り、頭上に「ニャー！」「ミャオ♪」などの吹き出しとジャンプアニメーションが発生する。
- [x] **ダブルクリック (増殖)**: 猫をダブルクリックすると「ぽんっ！」と子猫（異なる品種・毛色）が新しく分裂誕生し、匹数が増える。
- [x] **ドラッグ＆ドロップ**: 猫をマウスで掴んで自由な位置に運べる。
- [x] **猫の家 (退去・おやすみ)**: 猫を掴んで画面左下の「お家」にドラッグ＆ドロップすると、お家の中に吸い込まれるように縮小・フェードアウトし、画面から1匹消える（残り匹数とセーブデータも更新）。
- [x] **猫の家 (呼び出し)**: 「お家」をクリックすると、お家の中から新しい猫ちゃんが元気に飛び出してくる。
- [x] **おやつ機能**: 「🐟 おやつ」ボタン（またはSpaceキー）でお魚がステージに投下され、猫たちが駆け寄る。
- [x] **ねこじゃらし機能**: 「🪶 ねこじゃらし」ボタンをONにすると、マウスカーソルに猫たちがじゃれつく。
- [x] **セーブ＆ロード**: 「💾 セーブ」ボタン（またはCtrl+S）を押すと `accounts/save_data.json` およびブラウザストレージに保存され、次回起動時に復元される。
- [x] **猫図鑑**: 「📖 猫図鑑」ボタンで一緒にいる猫たちのプロフィール（名前、品種、性格、大きさ）一覧が表示される。
